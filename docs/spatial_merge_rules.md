# 空间列审计清单与 P3 协议合并逻辑

## 1. 空间阻断字段清单
经过对 `step7v3_2_P1_time_holdout_lead1F1.parquet` 数据的审计，当前数据中用于空间定位的核心地理空间主键为：`cell_id`。

## 2. P3 协议空间关联逻辑
在下周开展 P3 协议（10km, 50km, 100km 空间阻断）特征提取与数据构造时[cite: 2]，为了避免时空信息泄漏并保证交叉验证的严谨性，所有模块在进行数据拼接时必须严格遵守以下 Merge 逻辑：

*   **唯一主键**：所有外部生成的空间阻断折叠标签（Fold Labels）的关联，必须且只能使用 `cell_id` 作为合并主键。
*   **合并方式**：以当前特征矩阵为左表（Left Table），新生成的空间折叠标签映射表为右表（Right Table），进行 Left Join（左连接）操作。
*   **质量校验**：数据合并完成后，必须进行断言检查（Assert），确保没有任何因匹配失败产生的缺失值（NaN），防止在送入模型前发生空间特征错位或样本丢失。

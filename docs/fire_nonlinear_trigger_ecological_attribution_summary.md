# 火灾非线性触发机制生态学归因小结

P1 LightGBM 的 SHAP 蜂群图表明，月尺度火险并非由单一气象变量控制，而是由土地利用、地形、季节位相、人类可达性、植被状态和水分条件共同塑造。全局重要性最高的变量包括耕地比例、平均海拔、季节余弦项、距建成区距离、树冠覆盖、NDVI 与三个月累计降水，说明点火机会、燃料数量及其含水状态在不同背景下发生耦合。生态区雷达图进一步显示，在预设的四类物理驱动中，植被贡献占 35.9%–54.6%，干旱/水分占 27.0%–44.2%，风场占 12.4%–19.5%，火历史占 4.1%–14.6%；不同 BIOME 的贡献结构明显异质，因此全国统一阈值不宜直接解释为普适生态规律。

依赖曲线揭示了清楚的非线性阈值。距上次火灾月数由低十分位 37 个月升至高十分位 120 个月时，平均 SHAP 由 0.536 降至 −0.105，差值 −0.641；风险贡献约在 50–65 个月附近由正转负，提示近期火活动所代表的持续点火环境或易燃景观记忆，比简单的“休养越久、燃料越多”关系更符合本数据。三个月平均 VPD 在低值区快速下降，约 0.3–0.6 后转为弱负，随后在中等区间回升，高十分位相对低十分位仍下降 0.329，呈现显著的非单调响应。三个月累计降水的抑制效应更稳定：约 250–300 后 SHAP 明显转负，低、高十分位差为 −0.610，反映持续湿润对燃料可燃性的限制。上述结论是条件关联而非独立因果效应；变量相关性、生态区组成与模型交互均会改变 SHAP 方向，应结合分区样本量、火点数和不确定性进行解释。

数据依据：`04_shap_beeswarm.png`、`05_shap_dependence.png`、`05_nonlinear_trigger_summary.csv` 与 `06_biome_shap_group_contributions.csv`。

# 基于LightGBM模型的特征消融实验分析

为进一步评估不同物理过程变量对野火预测性能的贡献，本文基于 LightGBM 模型开展了特征消融实验。

完整特征模型包含84个物理预测变量，在2022年时间留出验证集上取得：

- AUPRC = 0.216253
- ROC-AUC = 0.945749
- Brier Score = 0.046531

的综合性能。

消融结果表明，不同物理信息对模型预测能力的影响存在明显差异。


## 1. 火历史信息对模型预测性能的影响

首先，剔除火历史变量导致模型性能出现最显著下降。

AUPRC由0.216253下降至0.148382，降低：

\[
\Delta AUPRC=-0.067871
\]

该结果说明野火发生具有显著的时空记忆特征，历史火行为信息是未来火灾风险预测的重要来源。

本研究中的火历史变量包括：

- 过去火事件滞后变量
- 12个月火发生次数
- 距最近一次火灾时间

这些变量能够刻画区域燃料变化、生态恢复过程以及火扰动后的持续影响。

因此，仅依赖当前气候和环境状态难以完全替代历史火信息，火灾预测不仅是环境状态识别问题，更包含明显的空间持续性和时间依赖机制。


## 2. 植被变量对模型预测性能的影响

其次，剔除植被变量后 AUPRC 仅下降0.002215。

这表明植被状态虽然提供额外信息，但其独立贡献相对有限。

可能原因是：

植被变量（NDVI、EVI、森林覆盖度）主要反映长期燃料条件，而部分植被压力信号已经能够通过气象和水分变量间接表达。

因此模型仍可利用其他环境变量保持较稳定预测能力。


## 3. 干旱相关变量对模型预测性能的影响

值得注意的是，去除干旱相关变量后 AUPRC 反而提升0.007634。

这并不意味着干旱因素对野火形成没有作用，而可能反映了特征冗余和模型复杂度之间的权衡。

一方面，干旱影响通常通过：

- 土壤水分降低
- 蒸散增强
- 植被胁迫

等过程体现。

同时，植被状态变量可能已经成为综合性的干旱响应代理。

另一方面，在树深度受限的 LightGBM 模型中，高相关性的干旱变量可能增加模型搜索空间并引入一定噪声。

因此，去除部分干旱变量后模型泛化性能出现轻微提升。


## 消融实验总结

总体而言，消融实验验证了火历史信息在野火预测中的主导作用。

同时说明植被和气候变量主要提供环境背景约束，多源物理特征之间存在一定的信息互补与冗余关系。
